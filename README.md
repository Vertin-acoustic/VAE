## 文件怎么分工

- `notebooks/`：你阅读、修改和运行的课堂。
- `docs/`：工具说明、学习记录和 Git 操作记录。
- `scripts/check_environment.py`：讲解者使用的环境体检，本课不要求读懂实现。
- `scripts/start_jupyter.ps1`：PyCharm 内置服务失败时的备用启动方式。
- `outputs/`、`.runtime/`：本机检查结果和临时配置，不提交到 Git。
