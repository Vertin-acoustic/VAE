## 文件怎么分工

- `notebooks/`：你阅读、修改和运行的课堂。
- `docs/`：工具说明、学习记录和 Git 操作记录。
- `scripts/check_environment.py`：讲解者使用的环境体检，本课不要求读懂实现。
- `scripts/start_jupyter.ps1`：PyCharm 内置服务失败时的备用启动方式。
- `scripts/plot_lesson03.py`：在独立进程绘制第 3 课本次运行的训练曲线，避开当前环境的绘图库冲突；不属于本课掌握要求。
- `outputs/`：只保留值得查看的实验结果。目前 `lesson03/` 下有两种学习率各一张 PNG 和一份 JSON；看图即可，JSON 是绘图数据，无需逐项阅读。
- `.runtime/`：本机环境配置与检查报告，平时不用查看。与 `outputs/` 一样不提交到 Git。

课件生成脚本、自动执行副本和检查截图已清理。后续临时验证在 `.runtime/` 下进行，检查完删除不需保留的产物；课堂入口始终是 `notebooks/`，不另存多份课件。`scripts/plot_lesson03.py` 是课堂运行所需工具，继续保留。
